VEHICLE CRASH SOUNDS
Played by src/crash-audio.js: one recorded crash per impact, picked by closing speed, plus
glass only when a pane broke, the tyre loop (tires.wav) for a skid and a debris settle after
very hard hits. All files mono OGG Vorbis (quality 4), 44.1 kHz, metadata stripped, 35 Hz
high-pass, trimmed with a 3-60 ms fade-in and a 0.2-0.55 s fade-out, loudness-matched with
ffmpeg (EBU R128 integrated: -18 LUFS bumps and glass, -17 medium, -16 heavy, -21 debris;
limited to about -1.5 dBTP). Freesound pages could not be opened from the build
environment, so each file was taken from a public copy whose own credits name the same
author, Freesound page and licence (listed per file), and the licence was cross-checked in
other projects' credits where possible.

crash-medium-3.ogg, crash-heavy-1.ogg
  "240713_2785-2_FR_Car_and_motorcycle_crash" by kevp888 (field recording)
  https://freesound.org/people/kevp888/sounds/746501/
  License: Creative Commons Attribution 4.0 International (CC BY 4.0)
  https://creativecommons.org/licenses/by/4.0/
  Obtained from the copy in the Corro project (kastwey/corro on GitHub,
  server/Packages/great-route/assets/sounds/accident.ogg), whose credits and embedded
  Vorbis comments carry the same author, source and license.
  Changes: stereo 48 kHz folded to mono 44.1 kHz. crash-heavy-1.ogg is 0.02-2.13 s with a
  0.4 s fade-out; crash-medium-3.ogg is 0.02-0.95 s (the impact and crunch) with a 0.3 s
  fade-out; loudness-matched as above.

ENGINE, BOAT AND TANK SOUNDS
Played by src/engine-audio.js: per class, loops recorded at known revs are pitched by the
simulated RPM and cross-faded (the player's vehicle), one loop per nearby traffic vehicle.
All files mono OGG Vorbis (quality 4), 44.1 kHz, metadata stripped. Each loop was cut from
a steady stretch of its source (revs measured from the harmonic spacing), high-passed at
28 Hz and low-passed at 7-12 kHz, its seam cross-faded (the end point moved within one
engine cycle to where the waveform best matches the start; equal-power when it does not),
set to -20 to -22 dBFS RMS, and followed by 0.2 s of its own start (the game loops at the
exact length). Freesound pages could not be opened from the build environment, so each
file was taken from a public copy whose own licence file names the same author, Freesound
page and licence (listed per file; SHA-256 of the copies matched their manifests where
given).

RENDERING TECHNIQUES
Written for this project in src/postfx3d.js, src/lighting3d.js and src/surfaces3d.js; no
third-party shader source is copied. The techniques follow published work:
- Scalable Ambient Obscurance — Morgan McGuire, Michael Mara, David Luebke (HPG 2012).
- Bloom downsample/upsample filters — Jorge Jimenez, "Next Generation Post Processing in
  Call of Duty: Advanced Warfare" (SIGGRAPH 2014).
- FXAA — Timothy Lottes (NVIDIA), fast approximate anti-aliasing.
- The ACES filmic fit is the one three.js r160 uses (MIT, vendor/three.r160.js); its inverse
  in city_hdr_pars is derived from it.
