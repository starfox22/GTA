# Continuous wheelie distance and milestones

- Track actual airborne metres in a compact animated HUD, with `GREAT!` beyond 100 m and `Amazing!` beyond 200 m.
- Hold a final landing result; pause safely and reject stationary balance, ground travel and relocation.
- Debounce tiny lifts/touchdowns and clear the tracked bike on crash, exit and world reset.

When a dispatch caption is visible, the meter becomes a compact row above it. The production CSS layout and reduced-motion rules pass desktop, phone and landscape fixtures; game JavaScript is byte-identical to the rendered/keyboard-tested release.
