# Docs and tooling for parallel agents
- Downloadable build: `python3 tools/build.py --zip dist/DeadEndCity.zip` (DeadEndCity/index.html,
  media/*.mp3, README.txt; plays from file://). `tools/media-check.mjs` checks the streamed tracks.
- CLAUDE.md; docs/FILEMAP.md generated by `tools/filemap.py` (check.sh warns when stale);
  the source guide split into docs/areas/; docs/README.md index.
- Changelog fragments in docs/changes/ folded by `tools/changelog.py`; older releases in
  docs/archive/CHANGELOG-archive.md.
- `tools/quick-check.sh` pre-commit check; `dead-end-city.html` is no longer tracked;
  `tools/extract_review_build.py` removed.
