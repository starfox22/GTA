# Fort Sentinel: recoverable running suspicion

Observed running now contributes 20 suspicion points per second: five observed seconds from an empty bar. Additional watching soldiers cannot multiply running pressure. Drill-only witnesses notice at half that rate. Ordinary walking or standing reduces suspicion by 12 points per second, even while visible, provided no other suspicious action is active. Releasing Run or movement stops running pressure immediately instead of waiting for the speed filter to settle.

The HUD shows **SUSPICION RISING**, the time left to walk again, and the current Run binding. It changes to **SUSPICION FADING** during recovery. Movement bindings are unchanged: under the disguise, W walks and Shift runs by default. Touch and remapped Run controls use the same action.

Restricted areas, climbing and face-to-face loitering retain their existing pressure. Visible weapons/assaults, gunfire, military-vehicle theft and pre-clearance trespass retain their alarm rules. Running after the warning bar reaches 100 still exposes the disguise and can fail the job before Records.
